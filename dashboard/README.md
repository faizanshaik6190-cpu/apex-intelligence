# Dashboard React frontend for Apex Intelligence

This folder contains the React dashboard for the Apex Intelligence owner.

## Features

- Real-time company status dashboard
- Lead management and approval
- Deal tracking and pricing
- Audit generation and review
- Delivery plan management
- Customer support tickets
- Voice interface to CEO agent
- Analytics and reporting

## Setup

```bash
cd dashboard
npm install
npm start
```

## Build

```bash
npm run build
```
